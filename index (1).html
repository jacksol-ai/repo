01 — dua keluarga papan

Dua jenis papan, dua filosofi desain

Keduanya berbentuk papan sirkuit tunggal, tapi apa yang berjalan di atasnya — dan untuk apa papan itu dibuat — sangat berbeda.

Single Board Computer

SBC

Komputer utuh yang dipadatkan ke satu papan: punya prosesor kelas smartphone, RAM, jalur penyimpanan, dan menjalankan sistem operasi penuh seperti Linux.

  • Bisa multitasking dan menjalankan banyak proses sekaligus
  • Terhubung ke layar, keyboard, jaringan seperti komputer biasa
  • Cocok untuk tugas berat: computer vision, server kecil, media center

Single Board Controller

SBM / mikrokontroler

Papan berbasis mikrokontroler yang fokus mengendalikan input dan output secara langsung, biasanya tanpa sistem operasi, hanya menjalankan satu program secara berulang.

  • Respons real-time yang bisa diandalkan waktu eksekusinya
  • Konsumsi daya sangat rendah, cocok untuk baterai
  • Cocok untuk sensor, motor, dan proyek embedded sederhana

04 — pengambilan keputusan

Jadi, pakai yang mana?

Cocokkan kebutuhan proyekmu dengan kekuatan masing-masing papan.

Pilih Single Board Computer jika...

  1. Proyek butuh menjalankan aplikasi berat: pengolahan gambar, AI ringan, atau server web
  2. Kamu ingin coding santai memakai Python dan library siap pakai
  3. Perlu koneksi jaringan, browser, atau tampilan grafis penuh
  4. Sumber daya listrik tersedia stabil, bukan dari baterai kecil

Pilih Single Board Controller jika...

  1. Proyek harus jalan dari baterai dalam waktu lama
  2. Butuh timing presisi, misalnya mengendalikan motor stepper atau PWM
  3. Perangkat harus langsung aktif tanpa proses booting
  4. Anggaran sangat terbatas dan tugasnya sederhana: baca sensor, gerakkan aktuator
05 — uji pemahaman

Kuis singkat

Lima pertanyaan untuk mengecek pemahamanmu tentang SBC dan SBC Controller.

GPIO
Pin serbaguna di papan yang bisa diatur sebagai input atau output digital.
RTOS
Sistem operasi ringan dengan jadwal eksekusi yang bisa diprediksi waktunya.
Bare-metal
Program yang berjalan langsung di atas perangkat keras, tanpa lapisan sistem operasi.
Deterministik
Sifat sistem yang responsnya bisa dipastikan waktunya, penting untuk kontrol real-time.
SoC
System on Chip, satu chip yang memuat prosesor beserta komponen pendukungnya.
eMMC
Jenis penyimpanan flash yang tertanam langsung di papan, alternatif microSD.
